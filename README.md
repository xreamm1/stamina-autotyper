# Stamina Online Auto Typer

Userscript для [stamina-online.com](https://stamina-online.com) — автоматически печатает текст уроков с настраиваемой скоростью. Работает поверх Tampermonkey, Greasemonkey, Violentmonkey.

> ⚠️ Это утилита «для спортивного интереса» — автопечать искажает статистику тренировки и не поможет научиться печатать быстрее. Используй осознанно.

---

## Возможности

- **Авто-детекция текущей клавиши** по красной подсветке `#FF0000` на виртуальной клавиатуре сайта. Работает независимо от классов и структуры DOM.
- **Регулируемая скорость** — от 1 до бесконечности знаков в минуту.
- **Humanize-jitter** (±90 %) — ритм можно сделать неидеальным.
- **Пауза на пробел** — настраиваемая дополнительная задержка между словами.
- **Sync-режим** — ждать смены подсветки перед следующим нажатием. Даёт ~100 % точности.
- **Дедупликация** — не нажимает одну и ту же клавишу дважды, пока сайт не сдвинул курсор.
- **Автоматический старт** через симуляцию «Пробел».
- **Разблокировка при залипании** — трёхступенчатая стратегия, если сайт не продвинулся: повтор → Shift+символ → сброс.
- **Горячие клавиши** — F8 (старт/стоп), F9 (сброс счётчика).
- **Диагностика в консоли** — кнопка в панели + режим подробных логов.
- **Draggable панель** справа сверху, сворачивается.
- **Настройки сохраняются** в `GM_setValue` / `localStorage`.
- **Изоляция от сайта** — ввод в панель не долетает до слушателей stamina, курсор не прыгает.

## Установка

1. Поставь менеджер userscript'ов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Safari)
   - [Violentmonkey](https://violentmonkey.github.io/) (Chrome, Firefox)
   - [Greasemonkey](https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/) (Firefox)
2. Открой [stamina-autotyper.user.js](./stamina-autotyper.user.js) в репозитории → нажми **Raw**.
3. Менеджер скриптов сам предложит установить. Жми «Install».
4. Открой [stamina-online.com](https://stamina-online.com) — в правом верхнем углу появится панель **⌨ Stamina Auto Typer**.

## Использование

1. Открой любой урок (например `ru/workout/lesson/51`).
2. Жми **▶ Старт** (или F8).
3. Скрипт сам нажмёт Пробел для старта и начнёт печатать.
4. Esc / **■ Стоп** — остановить.

### Рекомендуемые настройки

| Задача | Скорость | Humanize | Sync-режим |
|---|---|---|---|
| Максимальная точность | 1000-2000 | 20 % | **ON** |
| Естественный ритм | 300-500 | 40-60 % | ON |
| Максимальная скорость | 3000+ | 10 % | ON |
| Протестировать детектор | 100 | 0 % | OFF |

## Как работает

1. Каждые `60000 / cpm` миллисекунд (± humanize) скрипт сканирует DOM через `document.body.getElementsByTagName('*')`.
2. Для каждого видимого элемента проверяется `getComputedStyle(el).backgroundColor` — если это пурпурно-красный (R ≥ 200, G ≤ 60, B ≤ 60, R − max(G, B) ≥ 120) и текст элемента ровно один символ — это и есть «текущая клавиша».
3. Пробел-клавиша определяется отдельно: широкий (> 150 px) элемент с пустым или длинным текстом (`Space` / `Пробел`).
4. Диспатчит `keydown` → `keypress` → `keyup` на `document.body` с правильным `key`, `code`, `keyCode`, `charCode`, `shiftKey`. Событие bubbles к любому слушателю сайта **ровно один раз**.
5. В `sync_mode`: ждёт пока сигнатура подсвеченного элемента не изменится, прежде чем нажать следующую клавишу.
6. При залипании (сайт не продвигается 60-320мс) последовательно пробует: повтор нажатия → Shift+символ → полный сброс детектора.

## Разработка

Файл один, зависимостей нет. Правь напрямую в `stamina-autotyper.user.js`, перезагружай страницу — Tampermonkey/Violentmonkey подхватят обновление автоматически (при включённой опции).

Чтобы добавить селектор под другой сайт — скопируй блок про `isPureRed` и адаптируй цвет под тот, что твой тренажёр использует для подсветки.

## Отладка

Если не находит текущую клавишу:

1. Включи в панели галочку **«Диагностика в консоли»**.
2. Открой **F12 → Console**.
3. Жми **«Диагностика»** в панели.
4. Увидишь список: `red-background elements on page: N` и дамп всех элементов с красным фоном.
   - `N > 0` → детектор работает, но, возможно, ловит не ту клавишу.
   - `N = 0` → сайт использует другой цвет / background-image / canvas. Открой этот issue с диагностикой.
